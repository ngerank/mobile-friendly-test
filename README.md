# Mobile Friendly Test - Ngerank

A lightweight tool to simulate mobile view and check basic mobile friendliness of a website.

## Features
- Simulate mobile view (390px width)
- Detect basic page load success/failure
- Simple, fast, and clean dark mode design
- SEO-optimized footer with branding "Built to Rank"

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Usage
1. Enter the website URL you want to test.
2. Click "Analyze" to load the page inside a mobile-sized iframe.
3. See the result status and mobile preview.
